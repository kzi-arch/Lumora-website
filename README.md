## ✨ Tentang Lumora

**Lumora** adalah platform manajemen photobooth modern yang dirancang agar sangat mudah dipahami dan digunakan. Dengan Lumora, siapapun termasuk orang awam bisa menjalankan operasional photobooth tanpa kendala teknis yang rumit. Desain antarmukanya bersih, responsif, dan memberikan pengalaman pengguna (*user experience*) yang luar biasa.

## 🚀 Fitur Utama

- 📱 **Mobile-First Control:** Kelola mesin photobooth Anda dengan nyaman langsung dari genggaman (HP).
- 💻 **Kompatibilitas Windows:** Mendukung penuh berbagai jenis mesin yang menggunakan OS Windows, baik PC maupun Mini PC/PC Portabel.
- ♾️ **Unlimited Mesin:** Skalabilitas tinggi yang mendukung jumlah mesin tak terbatas (khusus Paket Enterprise).
- 🔒 **Keamanan Ekstra:** Dilengkapi dengan perlindungan *Security Headers* (HSTS, XSS Protection, dll) untuk menjaga keamanan data.
- 🎨 **Animasi Interaktif:** Pengalaman UI/UX yang mulus dengan transisi elegan menggunakan Framer Motion.
- 🛡️ **Garansi 30 Hari:** Layanan bebas risiko dengan garansi uang kembali 30 hari penuh.

## 🛠️ Teknologi yang Digunakan

Proyek ini dibangun menggunakan teknologi web modern untuk menjamin performa, keamanan, dan keindahan antarmuka:

- **Framework:** [Next.js](https://nextjs.org/) (App/Pages Router)
- **Library UI:** [React](https://reactjs.org/)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/)
- **Animasi:** [Framer Motion](https://www.framer.com/motion/)
- **Ikon & Komponen:** [Material-UI (MUI)](https://mui.com/)

## 📦 Cara Memulai (Development)

Ikuti langkah-langkah di bawah ini untuk menjalankan proyek Lumora di lingkungan lokal Anda:

1. **Clone repositori ini**
   ```bash
   git clone <url-repo-anda>
   cd lumora-website
   ```

2. **Install dependensi**
   Gunakan *package manager* pilihan Anda (NPM, Yarn, PNPM, atau Bun).
   ```bash
   npm install
   # atau
   yarn install
   ```

3. **Jalankan server *development***
   ```bash
   npm run dev
   # atau
   yarn dev
   ```

4. **Buka di Browser**
   Buka [http://localhost:3000](http://localhost:3000) di browser untuk melihat hasilnya.
